The kit now assumes no AI experience. Every skill talks in plain words, asks one question at a time with an example answer, accepts "I don't know", never asks you to type a command or edit a file, and builds a resume from conversation if you don't have one. Say "skip sales jobs" or "I applied to that one" and it updates your tracker itself. The README and diagram are rewritten around what you say, not which skill runs, and add install steps for the Claude desktop app.
