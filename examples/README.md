# Worked example: Jordan Rivera

This folder shows what the kit produces, so you can judge it before spending two hours on your own setup.

**Jordan Rivera is fictional.** So is every company, posting, number and link here. The files were written by hand to follow the formats in each `SKILL.md`. They are an illustration, not a captured run, and a real run will differ in wording.

## The five documents

What `career-setup` and `job-scout` leave in Jordan's `career/` folder:

| File | Look at it for |
| --- | --- |
| [resume-base.md](jordan-rivera/career/resume-base.md) | The starting resume. Note how flat the bullets are. |
| [search-criteria.md](jordan-rivera/career/search-criteria.md) | Hard filters and deal-breakers the scout enforces |
| [resume-story-bank.md](jordan-rivera/career/resume-story-bank.md) | The same accomplishments after the interview, plus open questions left blank instead of guessed |
| [resume-voice-profile.md](jordan-rivera/career/resume-voice-profile.md) | Rules with quoted evidence, banned words, approved examples |
| [job-scout-ledger.md](jordan-rivera/career/job-scout-ledger.md) | Feedback, applications, and roles already evaluated |

## What comes out

| File | Produced by |
| --- | --- |
| [job-scout-report.md](jordan-rivera/output/job-scout-report.md) | `job-scout`, one morning's run |
| [posting-larkspur.md](jordan-rivera/output/posting-larkspur.md) | The posting Jordan pasted in |
| [tailored-resume-larkspur.md](jordan-rivera/output/tailored-resume-larkspur.md) | `tailor-resume`, including the requirement map and the optional note |
| [interview-brief-larkspur.md](jordan-rivera/output/interview-brief-larkspur.md) | `interview-prep`, the one-page brief |

## What to notice

- Compare a bullet in `resume-base.md` with the same accomplishment in `tailored-resume-larkspur.md`. The facts are identical. The second one says what was broken first and sounds like a person.
- The tailored resume does not claim multi-site experience, because Jordan has none. The gap shows up in the map and again in the interview brief, with an honest answer.
- The scout report skips more roles than it reports, and says why for each.
